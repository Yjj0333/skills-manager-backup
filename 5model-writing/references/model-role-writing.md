# 建模章节角色化写作参考

本文件只在写具体子问题时按需读取。它把“结果怎么写”绑定到模型角色，而不是绑定到算法名。

## 角色与验收句式

| 角色 | 正文必须交代 | 可接受的证据 | 避免的表述 |
| --- | --- | --- | --- |
| 预测 | 时间/空间切分、基线、误差和区间 | 样本外 MAE/RMSE/覆盖率、滚动验证、稳定性 | 只报训练拟合优度或把相关写成因果 |
| 优化 | 决策、可行域、目标和解的质量 | 约束残差、目标界、最优间隙、运行时间、小规模精确基准 | 只报“收敛曲线”就称全局最优 |
| 机理 | 状态方程、初边值、单位和参数含义 | 量纲/守恒、参数可辨识性、拟合与外推、步长收敛 | 用黑箱拟合替代机制验证 |
| 评价/排序 | 指标方向、权重来源和排序对象 | 排序稳定性、逆序检查、权重扰动、外部效度 | 客观指标直接套 AHP 或把 TOPSIS 当万能模型 |
| 分类/聚类 | 标签来源、泄漏控制和类别结构 | 交叉验证、类别不平衡、校准、聚类稳定性或外部标签检验 | 只凭一张二维图宣布类别真实存在 |
| 网络/图 | 节点、边、方向、容量和流守恒 | 连通性、流量守恒、路径/割约束、扰动后结构稳定性 | 只画网络图而没有可行性检查 |
| 博弈 | 主体、行动顺序、信息和收益耦合 | 均衡存在性、无单边获利偏离、多均衡选择、集中式对照、政策敏感性 | 因题目是 B 题就强行添加博弈 |

## 一段结果的最小结构

每个子问题的结果段按“事实—证据—解释—边界”写四句：

1. **事实**：直接回答题面目标，给出实际输出或方向。
2. **证据**：指向结果表、图或验证指标，保留单位和精度。
3. **解释**：说明该输出如何由目标、约束或机制产生，避免把相关关系说成因果。
4. **边界**：说明数据范围、假设、最优间隙、外推风险或未验证因素。

若证据尚未生成，第四句改为“待运行/待核验”，并在建模章节交接中列出所需字段；不要用经验数字填空。

## 建模公式段的顺序

推荐用以下顺序连接公式，不要求固定编号或公式数量：

```text
输入/参数定义 -> 状态或派生关系 -> 目标函数 -> 约束与边界
-> 求解器及停止条件 -> 输出映射 -> 验证量
```

若模型由多个节点组成，先说明接口字段和变换，再给下游公式。新增变量必须注明来源：题面条件、附件数据、合理派生或显式假设。

## 敏感性与稳健性

只选会改变决策或预测的关键参数；扰动范围按物理上下界、置信区间、业务场景或数据分位数定义。正文至少报告：

- 参数变化与输出变化的对应关系；
- 是否改变最优方案、排序、预测区间或均衡；
- 结论是否对该变化稳定；
- 哪些范围没有被数据或机理覆盖。

不要把“±5%/±10%”当成默认科学依据，也不要把单次扰动结果写成普遍鲁棒性证明。

## 图表和表格交接

- 数据图的数值和图注来源于 `RESULTS_REPORT.md` 或 `figures/*`；概念流程图来源于 `DRAWIO_REPORT.md`。
- 每张图/表只回答一个问题，正文先引用再解释；图下写图注，表上写表注。
- 结果表只保留能支撑结论的列，完整数据留给结果附件；不要在正文粘贴代码或内部路径。
- 交给 `5writing` 时附上：建议章节、图表编号、来源、正文引用句和未解决的人工审阅项。
